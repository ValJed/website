Open source projects I contributed to:
 
- <a class="link" href="https://github.com/natecraddock/workspaces.nvim/pull/18" target="_blank" rel="noopener noreferrer">Nvim Workspace</a>

Neovim plugin to manage workspace directories.

- <a class="link" href="https://github.com/ajeetdsouza/zoxide/pull/1026" target="_blank" rel="noopener noreferrer">Zoxide</a>

Zoxide is a smarter cd command, inspired by z and autojump written in Rust.

- <a class="link" href="https://github.com/ValJed/task" target="_blank" rel="noopener noreferrer">Task</a>

Tiny tasks CLI written in Rust for unix based systems. Supports ssh2 to read and write on remote file, also supports API (see below).

- <a class="link" href="https://github.com/ValJed/task-api" target="_blank" rel="noopener noreferrer">Task Api</a>

Rust Api to store tasks from the CLI on a server, uses Sqlite. 

- <a class="link" href="https://github.com/ValJed/tomato" target="_blank" rel="noopener noreferrer">Tomato</a>

Pomodoro Rust TUI developed with <a class="link" href="https://ratatui.rs/" target="_blank" rel="noopener noreferrer">ratatui</a>.
